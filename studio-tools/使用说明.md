# 专用 RDP 客户端 使用说明

基于 FreeRDP **3.33.1**（Windows 客户端 `wfreerdp`）定制，对标 mstsc 的操作手感，
额外提供**后台文本注入**与**后台截图**，用于自动化。

- 部署目录：`C:\Users\13611\Documents\电脑管理\freerdp-98184\release\studio-1.0`
- 桌面图标：`FreeRDP.lnk` → `wfreerdp.exe`
- 源码：同仓库 `upstream\`，分支 `studio-rdp-client`
- 版本：`9f08c28`（含后台截图）

---

## 1. 组成

| 文件 | 作用 |
|---|---|
| `wfreerdp.exe` | 外壳程序，只负责加载插件 |
| `wfreerdp-client3.dll` | **我们改的代码全在这里**（对话框、浮条、粘贴、注入、截图） |
| `freerdp-client3.dll` | FreeRDP common 客户端库 |
| `freerdp3.dll` / `winpr3.dll` | FreeRDP 核心与运行时 |
| `libcrypto-3-x64.dll` / `libssl-3-x64.dll` | OpenSSL |
| `SendRdpInput.exe` | 后台输入/截图命令行工具（走 `WM_COPYDATA`） |
| `freerdp.ico` | 图标 |

> 更新客户端时，通常只需要替换 `wfreerdp-client3.dll`（必要时加 `SendRdpInput.exe`）。

## 2. 启动

### 图形方式

双击桌面 `FreeRDP`，在对话框里填地址/端口/用户/密码，勾选「保存密码」后连接。

- 凭据存入 Windows 凭据管理器，键名 `TERMSRV/<host>` 或 `TERMSRV/<host>:<port>`，下次自动回填。
- 证书使用 `/cert:ignore` 直连（内网自签场景），不再弹证书确认框。
- 记住上次连接的地址与密码，也记住上次选中的显示器。

### 命令行方式

```powershell
.\wfreerdp.exe /v:192.168.98.184 /u:DOMAIN\user /f /cert:ignore /kbd:unicode:on
```

对话框启动时会自动补上这些默认参数，等价于：

```
/f                     全屏
+toggle-fullscreen     允许退出全屏（浮条上的最小化/还原按钮依赖它）
+dynamic-resolution    窗口尺寸变化同步给远端
+auto-reconnect        断线自动重连
/gdi:sw                软件 GDI（文字更锐利，兼容性更好）
/bpp:32                32 位色
/kbd:unicode:on        Unicode 键盘（粘贴文本依赖它）
/cert:ignore           忽略证书
/log-level:WARN        日志级别
```

## 3. 全屏与多显示器

- 会话锁定到**启动时鼠标所在的那块显示器**，分辨率取该屏物理分辨率。
- 会话缩放（DPI）取该屏缩放比例：主屏 3840×2160@225%，副屏 2560×1440@150%。
- 显示器选择按**序号**持久化（`%LOCALAPPDATA%\FreeRDP\studio-monitor.txt`）。

### 画面模糊排查

按顺序排除：

1. **远端分辨率低于本机窗口** —— 最常见。远端墙纸/图标被放大即为此症状。
   解决：远端「显示设置」里把分辨率调到与客户端窗口一致；或让 RDP 以目标分辨率重开会话。
2. **远端会话 DPI 是 100%，而本机是 225%** —— 客户端会在连接时把本机缩放写进 `CS_CORE`，
   但**无法在会话中途修改已有会话的 DPI**（mstsc 同样不能）。需要注销一次远端会话或重启远端机器后重连。
3. **窗口模式下的 SmartSizing** —— 窗口模式是等比缩放（会有轻微模糊），全屏是 1:1。要看清晰文字请用全屏。

## 4. 顶部连接条（浮条）

全屏时顶部居中显示，鼠标靠近顶端出现；可在按钮以外的空白区域操作：

| 操作 | 行为 |
|---|---|
| 左右拖动条身 | 控制条在屏内左右移动 |
| 向下拖过约 2 个条高 | **退出全屏**，窗口随鼠标移动，松手落位 |
| 双击条身 | 切换全屏 |
| 图钉 | 固定 / 自动隐藏 |
| 最小化 | 最小化窗口 |
| 还原 | 切换全屏 |
| 关闭 | 断开连接 |

尺寸跟随所在屏幕的缩放（150% 屏 864×40，225% 屏 1296×60）。

## 5. 粘贴文本（Ctrl+V）

在客户端窗口里按 `Ctrl+V`，客户端把**本机剪贴板文本**通过 RDP 键盘通道逐字输入到远端。

- **不需要远端支持剪贴板重定向**（内网策略常禁用），因此远端无法粘贴回本机属于正常现象。
- 使用 **Unicode 键盘事件**，不受远端输入法/键盘布局影响。
- `CRLF` 只产生一次换行（不会行数翻倍）。
- 粘贴中按 `Esc` 立即中止；重复按 `Ctrl+V` 会被忽略。
- **客户端失焦/最小化时会继续粘贴**（每批发送前清除 `SuspendInput`）。

### 速率与完整性（实测，同一台远端、同一段 7600 字符）

| 节奏 | 实测速率 | 结果 |
|---|---|---|
| 1 字 / 5 ms | 179 cps | 完整 |
| **1 字 / 1 ms（默认）** | **632 cps** | **完整** |
| 1 字 / 0.5 ms | 1257 cps | 丢字 |
| 10 字 / 5 ms | 1769 cps | 丢字、串序 |

11,400 字符在默认速率下验证完整（300 行文本，行数、内容一致）。

### 调参（不改代码）

```powershell
$env:STUDIO_PASTE_PER_TICK = "5"    # 每批字符数，默认 1
$env:STUDIO_PASTE_TICK_MS  = "5"    # 每批间隔毫秒，默认 1
```

> 速率再往上会被远端输入队列丢弃（客户端侧零拒绝，丢在服务端），所以默认取 632 cps。

## 6. 后台注入（`SendRdpInput.exe`）

通过 `WM_COPYDATA` 直接把输入投给客户端进程，**不需要远端窗口在前台**，客户端最小化也有效。

窗口标题（仅主机名/IP）是匹配依据，因此**同一主机不要同时开多个客户端实例**。

```powershell
# 连接状态：Connected / Unicode / InputSuspended / TargetInBackground
.\SendRdpInput.exe --target 192.168.98.184:3389 --status query

# 输入文本（Unicode，逐字）
.\SendRdpInput.exe --target 192.168.98.184:3389 --text "hello 世界"

# 组合键：CTRL+A、SHIFT+TAB、WIN+R、F5、方向键、ENTER、ESC、BACKSPACE …
.\SendRdpInput.exe --target 192.168.98.184:3389 --key CTRL+A

# 滚轮：正数向上，负数向下
.\SendRdpInput.exe --target 192.168.98.184:3389 --wheel -3

# 空闲保活计数（查询已发送次数）
.\SendRdpInput.exe --target 192.168.98.184:3389 --keepalive 1

# 后台截图（见下一节）
.\SendRdpInput.exe --target 192.168.98.184:3389 --capture C:\rdpcap\shot.bmp

# 鼠标移动 / 单击 / 右键 / 按下 / 抬起（坐标是远端会话像素，左上角为原点）
.\SendRdpInput.exe --target 192.168.98.184:3389 --move 1920,1000
.\SendRdpInput.exe --target 192.168.98.184:3389 --click 40,2080       # 点开始按钮
.\SendRdpInput.exe --target 192.168.98.184:3389 --rclick 1800,300
.\SendRdpInput.exe --target 192.168.98.184:3389 --down 300,300        # 拖拽起手
.\SendRdpInput.exe --target 192.168.98.184:3389 --move 800,700
.\SendRdpInput.exe --target 192.168.98.184:3389 --up 800,700          # 拖拽收尾
```

`--click` 等价于「移动 + 左键按下 + 左键抬起」，一次调用完成；`--rclick` 为右键。
拖拽用 `--down` → `--move` → `--up` 三步。坐标取远端会话分辨率（例如 3840×2160 时任务栏在 y≈2080）。

返回码：`0` 成功并已投递；非 0 表示被拒绝（客户端会打印 `Client rejected input`）。

注入前客户端会临时清除 `SuspendInput`，发完还原，所以失焦状态不会丢输入。

## 7. 后台截图

```powershell
.\SendRdpInput.exe --target 192.168.98.184:3389 --capture C:\rdpcap\shot.bmp
```

- 数据源是客户端的**主画面缓冲**（服务端推来的最新一帧），客户端最小化时仍在更新，所以后台可截。
- 输出 **32 位未压缩 BMP**（自顶向下）：3840×2160 约 33 MB。
- 尺寸由位图对象取（`GetObject`），分辨率与当前会话一致。

用 Python 转 PNG：

```python
from PIL import Image
Image.open(r"C:\rdpcap\shot.bmp").convert("RGB").save(r"C:\rdpcap\shot.png")
```

### 限制

- 截到的是**客户端缓冲**：远端锁屏/UAC 安全桌面不推流，会截到上一帧。
- 会话完全断开（注销）后画面停止更新，截到最后一帧。
- 不含鼠标指针（指针是独立通道合成到窗口上的）。

## 8. 空闲保活（F15）

连续 **2 分钟无任何输入**（键盘、鼠标、注入的输入都算）发送一次 `F15`（扫描码 0x66），
有输入立即重新计时；持续空闲则每 2 分钟一次。

查询次数：

```powershell
.\SendRdpInput.exe --target 192.168.98.184:3389 --keepalive 1
```

## 9. 日志与排查

| 文件 | 内容 |
|---|---|
| `%TEMP%\studio-paste.log` | 粘贴：`PASTE_START/PASTE_DONE`、速率、取消 |
| `%TEMP%\studio-clip.log` | 剪贴板通道：`CLIPRDR_INIT`、`MONITOR_READY`、格式列表 |
| `%TEMP%\studio-capture.log` | 截图：位图指针、尺寸、保存结果 |
| `client.stderr.log`（部署目录） | 客户端运行日志（`/log-level:WARN`） |

常见症状：

| 症状 | 原因 / 处理 |
|---|---|
| Ctrl+V 没反应 | 客户端窗口需在前台才拦截 `Ctrl+V`；后台请用 `--text` |
| 粘贴丢字 | 速率过高，降 `STUDIO_PASTE_PER_TICK` 或加大 `STUDIO_PASTE_TICK_MS` |
| 行数翻倍 | 旧版本 CRLF 双换行 bug，已修（`9f08c28` 之后） |
| 文字变成汉字/乱码 | 旧版本用扫描码被远端输入法转换，已改 Unicode 事件 |
| 浮条按钮点不动 | 高 DPI 命中未缩放，已修（`7874cc9`） |
| 注入返回 rejected | 客户端未连接或窗口标题不唯一；`--status` 确认 |
| 截图文件没生成 | 看 `%TEMP%\studio-capture.log`，通常是路径无权限 |

## 11. 已知限制

- **会话 DPI 不能在会话中途修改**（受 RDP 协议限制，mstsc 同样不行）。
- **多屏 `+multimon` 为实验特性**：已枚举显示器并协商桌面尺寸，但只绘制主屏，副屏为黑；默认单屏全屏不受影响。
- 远端若禁用剪贴板重定向，**远端 → 本机**粘贴不可用（本机 → 远端由本客户端逐字输入实现）。
- 截图不含鼠标指针；锁屏/安全桌面截不到。
- 客户端窗口在前台时才会拦截 `Ctrl+V`（避免吞掉其它程序的粘贴）。
